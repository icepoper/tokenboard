Features

额度预警

任一周期剩余低于 20%，系统通知第一时间提醒，再也不怕用到一半停摆。

Keychain 安全存储

Setup

三步开始使用

01

下载安装

从 Releases 下载 Universal DMG，拖入 Applications。首次打开未签名应用时，在「系统设置 → 隐私与安全性」中选择「仍要打开」。

02

粘贴凭证

在千问 Token Plan 页面按 F12，从 Network 请求中复制 Cookie 与 sec_token，粘贴到设置窗口保存。

03

完成

菜单栏即刻出现双百分比胶囊，自动轮询刷新；点击面板刷新按钮可立即拉取最新数据。
